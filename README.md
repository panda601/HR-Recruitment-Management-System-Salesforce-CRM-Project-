# HR-Recruitment-Management-System-Salesforce-CRM-Project-
The HR Recruitment Management System is an end-to-end hiring and candidate tracking solution built on Salesforce. It streamlines job posting, candidate management, screening, interview scheduling, and offer processing—designed to help HR teams automate manual work and gain full visibility into the hiring funnel.

1. Recruitment Dashboard This dashboard provides a comprehensive view of the recruitment pipeline, showing open positions, active applicants, and a task list for recruiters.







2. Applicant Profile A detailed view of a candidate, John Doe, applying for a "Job Flow Manager" position. It includes his contact details, current application stage, and a preview of his resume.






3. Interview Scheduling Recruiters can easily schedule an interview with John Doe directly from his profile. This image shows a calendar view with available time slots and options to select interview type and participants.






4. Offer Letter Generation Once a candidate is selected, an offer letter can be generated and sent directly from the CRM. This image displays a preview of the formal offer letter for John Doe, with options to send it via email or download it.
